Setup help

Connect

  • Use Google Chrome or Edge. USB serial and USB Ethernet (http://phone-poc.local/) need no driver.
  • Board page doesn't load and Device Manager shows code 10 on the board's network adapter: update the firmware over USB serial.

Firmware update

  • The browser only lists STM32 BOOTLOADER when it has the WinUSB-based ST driver. Install STM32CubeProgrammer 2.24 and let it install the DFU driver.
  • Already installed, or the board is still not listed: run as administrator 
    C:\Program Files\STMicroelectronics\STM32Cube\STM32CubeProgrammer\Drivers\DFU_Driver\STM32Bootloader.bat
  • Check: in Device Manager, STM32 BOOTLOADER sits under Universal Serial Bus devices. Older ST DFU drivers (STTub30) don't work with the browser.

Connect

  • Use Google Chrome from Google's .rpm/.deb package, not the Flatpak: in the Flatpak sandbox Chrome lists no serial ports and does not resolve phone-poc.local.
  • Serial access denied? Add yourself to the dialout group, then log out and in. untested (Fedora needs nothing) 
    sudo usermod -aG dialout $USER

Firmware update

  • The ST bootloader belongs to root, so Chrome gets "Access denied". Allow the desktop user once, then replug the board: 
    echo 'SUBSYSTEM=="usb", ATTR{idVendor}=="0483", ATTR{idProduct}=="df11", TAG+="uaccess"' | sudo tee /etc/udev/rules.d/70-stm32-dfu.rules
sudo udevadm control --reload && sudo udevadm trigger --subsystem-match=usb --attr-match=idVendor=0483

Connect

  • Use Google Chrome or Edge. Nothing to install. Safari has no Web Serial or WebUSB.
  • Board page doesn't load in Chrome or Brave: System Settings → Privacy & Security → Local Network, turn on the browser and its Helper (Aperitif) entries.

Firmware update

  • Nothing to install.

Connect

  • Use Chrome and tap Connect USB serial.
  • The board is listed twice? Pick the entry with the serial number, or close Chrome completely and try again.
  • USB Ethernet (http://phone-poc.local/) does not load? Allow Chrome's local network permission: Settings → Apps → Chrome → Permissions.

Firmware update

  • Works over USB serial (tested on a Pixel 2). Nothing to install.

Connect

  • iPhone and iPad browsers have no USB serial: use USB Ethernet. Plug the board into the USB-C port, wait about 5 s and open http://phone-poc.local/ (Open board page).
  • Chrome and other browsers ask for Local Network access; allow it. Denied by mistake: Settings → Chrome → Local Network.
  • Offline use: on the board page tap Share → Add to Home Screen.

Firmware update

  • Use the Firmware update section on the board page (through the network updater). Nothing to install.
